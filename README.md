# 鼎码智辅 (DingCoder-AI)

一个基于IntelliJ IDEA的AI代码生成插件，帮助开发者快速生成校验器代码。

## 功能特性

- 🤖 AI驱动的代码生成
- 🔐 用户认证系统
- 💬 实时聊天界面
- 📝 智能输入框（支持多行输入、自动调整高度）
- 🎨 现代化UI设计（参考通义灵码风格）
- 📁 批量代码生成
- 🔄 MQTT实时通信

## 最新更新

### 输入框样式改进 (v1.0.1)

参考通义灵码的设计风格，对输入框进行了全面改进：

#### 🎨 视觉改进
- **圆角设计**: 输入框和按钮采用8px圆角，更加现代化
- **焦点效果**: 输入框获得焦点时边框变为蓝色高亮
- **颜色主题**: 支持浅色/深色主题自动切换
- **字体优化**: 优先使用PingFang SC字体，提升中文显示效果

#### 🔧 功能增强
- **自适应高度**: 输入框根据内容自动调整高度（最大6行）
- **智能换行**: 支持Shift+Enter换行，Enter发送消息
- **状态反馈**: 发送按钮在不同状态下显示不同颜色和文字
- **悬停效果**: 按钮悬停时颜色变化，提供更好的交互反馈

#### 🎯 用户体验
- **更大的点击区域**: 按钮尺寸优化，更容易点击
- **清晰的状态指示**: 发送中、禁用、可用状态一目了然
- **流畅的动画**: 高度调整和状态切换更加平滑

## 安装说明

1. 下载插件jar文件
2. 在IntelliJ IDEA中安装插件
3. 重启IDE
4. 在工具窗口中找到"鼎码智辅"面板
5. 登录后即可使用

## 使用方法

1. **登录**: 点击登录按钮，输入用户名和密码
2. **输入API名称**: 在输入框中输入API名称或校验器名称
3. **生成代码**: 点击发送按钮，AI将自动生成对应的校验器代码
4. **批量生成**: 生成完成后可以点击"批量生成"按钮一次性生成所有文件

### 输入格式示例

```
bm.pre_item.create:VD_pre_item_00012,VD_pre_item_00015
```

多个校验器之间用逗号隔开。

## 技术栈

- **Java 8+**
- **IntelliJ Platform SDK**
- **Spring Web** (HTTP客户端)
- **Eclipse Paho MQTT** (实时通信)
- **Gson** (JSON处理)

## 开发环境

```bash
# 克隆项目
git clone [repository-url]

# 进入项目目录
cd dingcoder-ai

# 构建项目
./gradlew build

# 运行测试
./gradlew test

# 运行IDE
./gradlew runIde
```

## 配置说明

插件支持以下配置：

- **服务器地址**: 在`CommonConstant.java`中配置
- **主题适配**: 自动适配IDE的浅色/深色主题
- **字体设置**: 优先使用系统中文字体
