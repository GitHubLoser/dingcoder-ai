# 鼎码智辅 (DingCoder-AI)

一个基于IntelliJ IDEA的智能AI开发助手插件，集成代码生成和代码审查两大核心功能，帮助开发者提升开发效率。

## 🚀 功能特性

### 🤖 AI代码生成
- **智能代码生成**: 根据API名称或校验器名称自动生成对应的Java代码
- **批量代码生成**: 支持一次性生成多个校验器文件
- **实时聊天界面**: 类似通义灵码的现代化聊天界面
- **智能输入框**: 支持多行输入、自动调整高度、智能换行
- **代码预览**: 生成的代码可直接在IDE中预览和编辑

### 🔍 AI代码审查
- **文件级审查**: 支持单个或多个文件的代码质量审查
- **变更审查**: 自动获取Git变更并进行智能审查
- **代码片段审查**: 支持选中代码片段的专项审查
- **实时反馈**: 通过MQTT实时接收审查结果
- **用户反馈**: 支持对审查结果进行确认或误报反馈

### 🔐 用户认证系统
- **安全登录**: 基于RSA+AES加密的用户认证
- **自动重连**: MQTT连接自动重连机制
- **状态管理**: 登录状态自动检查和维护

### 🎨 现代化UI设计
- **双标签页设计**: 代码生成和代码审查功能分离
- **圆角设计**: 参考通义灵码的现代化UI风格
- **主题适配**: 自动适配IDE的浅色/深色主题
- **响应式布局**: 支持窗口大小调整

### 🔄 实时通信
- **MQTT消息**: 基于MQTT的实时消息通信
- **异步处理**: 非阻塞的异步API调用
- **消息缓存**: 智能的消息缓存和重试机制

## 📋 系统架构

### 核心模块
- **代码生成模块**: `ChatToolWindowPanel` - 处理代码生成功能
- **代码审查模块**: `CodeReviewPanel` - 处理代码审查功能
- **认证模块**: `AuthService` - 用户认证和会话管理
- **通信模块**: `MQTTService` - MQTT消息处理
- **API服务**: `ReviewService`、`CodeGenerationService` - 后端API调用

### 技术栈
- **Java 8+**
- **IntelliJ Platform SDK**
- **Spring Web** (HTTP客户端)
- **Eclipse Paho MQTT** (实时通信)
- **Gson** (JSON处理)
- **Apache Commons** (工具库)

## 🛠️ 安装说明

1. 下载插件jar文件
2. 在IntelliJ IDEA中安装插件
3. 重启IDE
4. 在工具窗口中找到"鼎码智辅"面板
5. 登录后即可使用

## 📖 使用方法

### 代码生成功能

1. **登录**: 点击登录按钮，输入用户名和密码
2. **输入API名称**: 在输入框中输入API名称或校验器名称
3. **生成代码**: 点击发送按钮，AI将自动生成对应的校验器代码
4. **批量生成**: 生成完成后可以点击"批量生成"按钮一次性生成所有文件

#### 输入格式示例
```
bm.pre_item.create:VD_pre_item_00012,VD_pre_item_00015
```
多个校验器之间用逗号隔开。

### 代码审查功能

#### 文件审查
1. **添加文件**: 点击"+"按钮添加要审查的文件
   - 添加当前文件
   - 添加选中代码片段
   - 选择项目文件
2. **开始审查**: 点击"开始评审"按钮
3. **查看结果**: 在评审结果区域查看审查结果

#### 变更审查
1. **获取变更**: 点击"评审变更"按钮自动获取Git变更
2. **自动审查**: 系统自动对变更内容进行审查
3. **查看结果**: 在评审结果区域查看审查结果

#### 反馈功能
- **确认评审**: 点击"✓"按钮确认评审意见
- **误报反馈**: 点击"✗"按钮标记为误报并填写原因

## 🎨 UI特性

### 输入框样式改进
- **圆角设计**: 输入框和按钮采用8px圆角，更加现代化
- **焦点效果**: 输入框获得焦点时边框变为蓝色高亮
- **颜色主题**: 支持浅色/深色主题自动切换
- **字体优化**: 优先使用PingFang SC字体，提升中文显示效果

### 功能增强
- **自适应高度**: 输入框根据内容自动调整高度（最大6行）
- **智能换行**: 支持Shift+Enter换行，Enter发送消息
- **状态反馈**: 发送按钮在不同状态下显示不同颜色和文字
- **悬停效果**: 按钮悬停时颜色变化，提供更好的交互反馈

## 🔧 开发环境

```bash
# 克隆项目
git clone [repository-url]

# 进入项目目录
cd dingcoder-ai

# 构建项目
./gradlew build

# 运行测试
./gradlew test

# 运行IDE
./gradlew runIde
```

## ⚙️ 配置说明

插件支持以下配置：

- **服务器地址**: 在`CommonConstant.java`中配置
- **主题适配**: 自动适配IDE的浅色/深色主题
- **字体设置**: 优先使用系统中文字体
- **MQTT配置**: 在`MQTTService`中配置MQTT连接参数
