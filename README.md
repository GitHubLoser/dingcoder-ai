# 鼎码智辅 - IntelliJ IDEA 插件

鼎码智辅是一款集成在 IntelliJ IDEA 中的智能代码助手插件。它通过与后端 AI 服务通信，帮助开发者生成、理解和管理代码。

## ✨ 功能特性

- **用户认证**：提供安全的登录机制。
- **智能聊天**：在 IDEA 中与 AI 助教直接对话，获取代码建议和解决方案。
- **实时代码生成**：通过与后端 API 和 MQTT 服务集成，实时接收 AI 生成的 Java 代码。
- **交互式代码展示**：
    - 生成的代码块默认折叠，只显示文件名，保持界面整洁。
    - 可点击展开/收起，查看完整代码。
- **一键文件生成**：
    - **单个文件生成**：在每个代码块标题旁，都有一键生成 `.java` 文件的按钮。
    - **批量文件生成**：当所有代码生成完毕后，提供一个"批量生成全部文件"的按钮。
- **智能目录选择**：
    - 自动将文件生成在你在"项目视图"中选中的目录。
    - 如果未选择任何目录，会使用项目的默认源码路径 (`src/main/java`)。

## 🚀 快速开始

### 安装插件

1.  **构建插件**:
    ```bash
    ./gradlew clean buildPlugin
    ```
    构建成功后，插件 `zip` 文件会生成在 `build/distributions/` 目录下。

2.  **安装到 IDEA**:
    - 打开 IntelliJ IDEA (2020.3 或更高版本)。
    - 进入 `Settings/Preferences` -> `Plugins`。
    - 点击齿轮图标，选择 `Install Plugin from Disk...`。
    - 选择上面生成的 `zip` 文件并重启 IDEA。

### 使用方法

1.  **打开插件**:
    - 安装重启后，插件的工具窗口会自动出现在 IDEA 的右侧边栏。
    - 如果没有出现，可以通过 `View` -> `Tool Windows` -> `鼎码智辅` 打开。
2.  **登录**:
    - 首次使用需要登录。
3.  **开始对话**:
    - 在输入框中输入你的需求（例如 API 名称或功能描述），点击"发送"或按回车。
    - 插件会立即显示"正在为您生成代码，请稍候..."。
4.  **查看和生成代码**:
    - AI 生成的代码会以折叠形式显示在聊天窗口中。
    - 点击文件名可展开查看完整代码。
    - 点击"生成Java文件"按钮即可将代码保存为文件。
    - 所有代码生成结束后，可使用"批量生成全部文件"按钮一次性生成所有文件。

## 🔧 开发构建

### 环境要求

-   **Java**: JDK 17 或更高版本。
-   **Gradle**: 项目使用 Gradle Wrapper，无需手动安装。

### 主要命令

-   **完整构建**:
    ```bash
    ./gradlew build
    ```
-   **运行测试**:
    ```bash
    ./gradlew test
    ```
-   **打包插件 (zip)**:
    ```bash
    ./gradlew buildPlugin
    ```

### Java 版本问题

如果在构建时遇到 Java 版本不兼容的错误，请确保你的 `JAVA_HOME` 环境变量指向了正确的 JDK 17+ 路径，或者在 `gradle.properties` 文件中指定 `org.gradle.java.home`。

## 🛠️ 技术栈

-   **核心语言**: Java 17
-   **IDE 平台**: IntelliJ Platform SDK
-   **网络通信**: Spring RestTemplate (HTTP), Eclipse Paho (MQTT)
-   **构建系统**: Gradle
